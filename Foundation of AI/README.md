## Review method
1. Read the module and explain each concept without notes.
2. Re-derive all formulas on paper, checking assumptions and dimensions.
3. Solve the practice questions before consulting lecture notes.
4. Mark concepts complete only when you can explain and solve a new example.

Lecture 11 develops binary classification and Bernoulli likelihood; Lecture 12 derives the logistic log-likelihood gradient and discusses ascent/descent and step size. No additional topics are assumed to be in the lectures.
