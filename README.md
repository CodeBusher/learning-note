# Learning Notes

Hey, welcome! This is where I keep my notes from courses, workshops, and whatever I happen to be learning at the moment. I'm sharing them here and hope you find something useful!

You can read everything right here on GitHub. If you'd rather have a local copy:

```bash
git clone https://github.com/CodeBusher/learning.git
```

These are personal notes and very much a work in progress, so some parts are still rough.

If something doesn't make sense, looks wrong, or you just want to talk through a topic, feel free to [open an issue](https://github.com/CodeBusher/learning/issues). And if you've got a fix or a clearer way to explain something, [pull requests](https://github.com/CodeBusher/learning/pulls) are always welcome, no matter how small.

Thanks for stopping by, and happy learning!
